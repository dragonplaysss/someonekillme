4. Information We May Process

The information Shorekeeper processes depends on the features enabled in a server and the interactions you have with the Bot.

Discord Information

  • Discord user IDs.
  • Discord usernames.
  • Display names.
  • Server nicknames.
  • Avatar information.
  • Guild/server IDs.
  • Channel IDs.
  • Role information.
  • Permission information.
  • Command and interaction information.
  • Timestamps.

The exact information available to Shorekeeper depends on Discord permissions, intents, server configuration, and the functionality being used.

5. Server Configuration Data

Shorekeeper may store configuration information necessary to operate enabled features.

  • Server/guild IDs.
  • Enabled or disabled modules.
  • Moderation configuration.
  • Anti-Nuke configuration.
  • Security settings.
  • Role IDs.
  • Channel IDs.
  • Command configuration.
  • Feature-specific settings.

6. Moderation and Security Data

When moderation or security functionality is used, Shorekeeper may record:

  • Target Discord user ID.
  • Moderator Discord user ID.
  • Action performed.
  • Reason.
  • Duration.
  • Case ID.
  • Timestamp.
  • Security event information.
  • Audit-log attribution information where available.

This information is used to provide moderation history, security functionality, accountability, and administrative tools.

7. Roblox Information

When Roblox features are used, Shorekeeper may process:

  • Roblox usernames.
  • Roblox user IDs.
  • Roblox presence information.
  • Game/place information.
  • Roblox avatar information.
  • Roblox authentication request information.

Roblox information is used only for the Roblox functionality requested or configured by authorized users.

8. Roblox Authentication Information

Certain Shorekeeper features may allow authorized server personnel to configure Roblox authentication functionality.

Authentication information is sensitive and must not be intentionally exposed through public Discord channels.

Where authentication information is processed, it is used only for the requested authentication workflow and related security functionality.

The developer should not retain authentication credentials longer than reasonably necessary for the feature to function.

Where credentials or authentication secrets are no longer necessary, they may be deleted according to the Service's retention practices.

9. Logs

Shorekeeper may maintain operational and event logs necessary to operate, troubleshoot, secure, and administer the Service.

Logs may contain:

  • Guild IDs.
  • User IDs.
  • Command/event information.
  • Timestamps.
  • Error information.
  • Moderation events.
  • Security events.

Shorekeeper should not intentionally record passwords, authentication secrets, API keys, tokens, or other sensitive credentials in ordinary operational logs.

10. How Information Is Used

Shorekeeper may use information to:

  • Execute commands.
  • Perform moderation actions.
  • Provide security features.
  • Detect potentially destructive activity.
  • Maintain server configuration.
  • Maintain moderation cases.
  • Provide Roblox functionality.
  • Complete requested authentication workflows.
  • Troubleshoot failures.
  • Maintain service reliability.
  • Prevent abuse.
  • Protect the Service and its users.
  • Comply with applicable legal obligations.

11. Data Sharing

Shorekeeper does not intentionally sell personal information.

Information may be transmitted to third-party services when necessary to provide a requested feature.

For example, Roblox-related commands may communicate with Roblox services to retrieve requested Roblox information.

Discord processes information according to Discord's own policies and terms.

12. Data Retention

Information is retained only for as long as reasonably necessary for the purposes described in this Privacy Policy, unless a longer period is required for legal, security, or legitimate operational purposes.

Retention periods may vary depending on the type of information.

Server configuration may remain while the server uses Shorekeeper. Moderation records may remain while required for moderation history and security. Operational logs may be retained for troubleshooting and security purposes.

13. Data Deletion

If Shorekeeper is removed from a server, server-specific data may be scheduled for deletion subject to operational, security, backup, and legal requirements.
